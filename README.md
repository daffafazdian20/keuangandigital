# Keuangan Digital — Frontend (GitHub Pages)

Frontend statis (HTML/CSS/JS). Backend: Google Apps Script (REST API). Login: Google Sign-In.

- `index.html` harus berada di root repository.
- Isi `js/config.js` (`GAS_URL` dan `GOOGLE_CLIENT_ID`) sebelum `git push`.
- Panduan lengkap: `PANDUAN-INSTALASI.md`.
